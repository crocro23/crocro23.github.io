# 🧠 Obsidian, mon coffre de notes centralisé

Pour m'organiser, j'ai choisi d'utiliser Obsidian :

1. 🖥️ une version sur mon PC : https://obsidian.md/fr/download
2. 📱 une version sur mon smartphone
3. ☁️ un abonnement Obsidian Sync à 52 €/an pour relier les deux appareils

J'ai créé un coffre partagé et j'y ai connecté les applications sur PC et Android. Tout est expliqué sur leur site : https://obsidian.md/fr/help/sync/setup

Le résultat est simple et puissant : le tout est répliqué entre mon téléphone et mon PC. 🚀
En résumé, mon système repose sur 3 piliers :

- 🧠 Obsidian comme espace central
- 🗂️ la méthode PARA pour structurer les informations
- ☁️ la synchronisation multi-appareils pour tout garder à jour
C'est une base solide pour organiser mes idées, mes notes, mes liens, mes tâches et mes références sans perdre de temps.

## 🗂️ La méthode PARA

J'utilise la méthode PARA pour ranger mes notes. Les 4 catégories sont :

- 🧩 P - Projets : tâches à court terme avec une échéance et un objectif précis  
  Exemple : _Rédiger un article_, _Préparer un voyage_

- 🏢 A - Areas (Domaines) : responsabilités de vie à maintenir sur le long terme sans date de fin  
  Exemple : _Santé_, _Finances_, _Maison_

- 📚 R - Resources (Ressources) : sujets d'intérêt continu ou matériel de référence pour plus tard  
  Exemple : _Notes sur le codage_, _Idées de recettes_

- 🗄️ A - Archives : éléments inactifs provenant des trois premières catégories  
  Exemple : projets terminés, anciennes ressources

Chaque note est écrite en Markdown. Voici la syntaxe de base :

- **Gras** : `**texte**` ou `__texte__`
- *Italique* : `*texte*` ou `_texte_`
- ~~Barré~~ : `~~texte~~`
- Titres : de `# Titre 1` à `###### Titre 6`
- Listes à puces : `-`, `*` ou `+`
- Listes numérotées : `1.`, `2.`, etc.
- Citations : `> Texte de la citation`
- Liens : `[Texte du lien](https://url.com)`
- Images : `![Texte alternatif](https://url-image.jpg)`
- Code en ligne : `` `code` ``
- Bloc de code : encadré par trois accents graves
- Tableaux : colonnes séparées par des barres verticales `|`

## ✅ Je fais aussi la migration de mon TO-DO

1. 📤 J'exporte les tâches dans un PDF
2. 📄 Le contenu du PDF est transformé en CSV au format UTF-8
3. 📥 J'importe les notes via le module d'importation d'Obsidian
4. ✨ Je corrige les quelques notes qui posent problème

Cela permet de conserver un historique exploitable tout en réorganisant la matière dans un système plus lisible.
